電路圖與圖示資料夾說明
========================

此資料夾用於存放所有演算法的電路圖和相關圖示。

命名規則：
----------
檔案名稱必須與演算法的節點名稱完全一致（區分大小寫）

例如：
- Shor.png 或 Shor.jpg 或 Shor.svg
- QFT.png
- Grover.png
- HHL.png
- HSP.png

支援的圖片格式：
---------------
- .png (推薦，透明背景)
- .jpg / .jpeg
- .svg (向量圖，推薦用於電路圖)
- .gif
- .webp

使用方式：
---------
1. 將電路圖文件放入此資料夾
2. 確保檔名與data.js中的算法名稱一致
3. 系統會自動在詳細資訊面板中顯示對應的電路圖

範例：
-----
data.js中: { name: 'Shor', ... }
對應圖片: Circuit_Graph/Shor.png

如果找不到對應圖片，會顯示預設文字說明。
