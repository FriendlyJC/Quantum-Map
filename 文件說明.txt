量子電腦演化史地圖 - 文件功能說明
===========================================

📁 專案文件結構
---------------

1. index.html
   - 網頁主文件
   - 定義頁面結構和HTML元素
   - 引入MathJax數學公式庫
   - 通常不需要修改

2. styles.css ⭐
   - 樣式表文件
   - 控制顏色、字體、布局
   - 修改外觀時編輯此文件
   - 例如：修改面板樣式、字體大小

3. app.js ⭐⭐
   - 主要程序邏輯文件
   - 處理繪圖、拖曳、縮放、點擊
   - 修改背景顏色區域時編輯此文件
   - 修改時間軸設置
   - 較少需要修改

4. data.js ⭐⭐⭐ 【最重要！】
   - 所有數據內容文件
   - 包含所有算法、標題、詳細資訊
   - 這是您最常修改的文件！
   - 修改內容請編輯此文件：
     * 算法名稱、年份、位置
     * 詳細說明文字
     * 數學公式

5. README.md
   - 專案說明文件
   - 介紹專案功能和使用方法
   - Markdown格式

6. 使用说明.md ⭐⭐⭐
   - 詳細使用教學
   - 如何修改數據
   - 如何添加數學公式
   - LaTeX語法說明
   - 強烈建議閱讀！

7. 文件说明.txt
   - 本文件
   - 快速文件功能說明

8. Circuit_Graph/ ⭐⭐ 【電路圖資料夾】
   - 存放所有算法的電路圖
   - 圖片命名必須與算法名稱一致
   - 支持 png, jpg, svg 等格式
   - 點擊節點時自動顯示對應圖片


===========================================
🎯 我想做什麼，應該修改哪個文件？
===========================================

想修改算法資訊 → data.js
想添加新算法 → data.js
想修改詳細說明 → data.js
想添加數學公式 → data.js（參考使用说明.md）

想修改顏色 → app.js (背景) 或 styles.css (面板)
想修改字體大小 → styles.css
想修改面板樣式 → styles.css

想修改時間軸範圍 → app.js
想修改繪圖邏輯 → app.js (進階)


===========================================
📝 快速上手指南
===========================================

1. 打開 data.js 文件
2. 找到要修改的部分
3. 修改文字或添加內容
4. 如要添加數學公式：
   - 行內公式用 $公式$
   - 獨立公式用 $$公式$$
   - 特殊符號用 \\ (如 \\sum, \\alpha)
5. 保存文件
6. 在瀏覽器中刷新 index.html (F5)


===========================================
💡 數學公式快速範例
===========================================

// 簡單變數
$n$ 個量子位元

// 上下標
$2^n$ 和 $x_i$

// 分數
$\\frac{a}{b}$

// 求和
$\\sum_{i=1}^{n}$

// 量子態
$|\\psi\\rangle$

// 獨立公式（居中顯示）
$$H = -\\sum_i h_i Z_i$$
